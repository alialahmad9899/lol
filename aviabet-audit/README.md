# AviaBET Demo Audit Toolkit

مشروع مستقل داخل المستودع، ولا يغيّر برنامج Store.exe أو ملفات التقارير القديمة.

## الغرض

هذه الأداة مخصصة لتدقيق بيانات الجولات التجريبية التي يرفعها المشغّل بنفسه:
- تدقيق جودة سجل الجولات واكتشاف الصفوف المكررة أو غير الصالحة.
- حساب ملخصات وصفية واختبارات ارتباط/تتابع أولية.
- مقارنة النتائج على أنها بيانات تاريخية فقط، لا توقعات مؤكدة.
- استقبال CSV عبر بوت Telegram خاص ومقيّد بمعرّفات محادثات مسموح بها.
- توفير دالة تحقق SHA-512 لمدخل معروف بعد الجولة، بشرط أن تكون صيغة البيانات الأصلية موثقة من مزوّد اللعبة.

**هذه الأداة لا تتنبأ بمعامل الجولة القادمة، ولا تنفّذ رهانات أو Cash Out، ولا تتصل بخوادم Pascal، ولا تجمع أسراراً أو بيانات جلسات.** التحليل الإحصائي لا يثبت وحده قابلية التنبؤ أو عدمها.

## بنية CSV

يجب أن يحتوي الملف على عمودين إلزاميين:
- round_id: معرّف الجولة.
- multiplier: معامل الانفجار النهائي.

يمكن إضافة timestamp بصيغة ISO-8601 مع منطقة زمنية، مثل 2026-11-18T10:00:00Z. إذا كانت كل الصفوف تحتوي على timestamp يرتّب البرنامج بحسب الوقت. وإلا، إذا كانت كل المعرفات رقمية، يرتّبها تصاعدياً. في غير ذلك يحافظ على ترتيب الصفوف كما وردت في CSV، لذلك يجب أن يكون الملف مرتباً من الأقدم إلى الأحدث.

مثال:

    round_id,multiplier,timestamp
    1001,1.24,2026-11-18T10:00:00Z
    1002,2.18,2026-11-18T10:01:00Z

يوجد ملف عينة في data/sample_rounds.csv مأخوذ من سجل Demo شوهد أثناء الفحص. العينة صغيرة ولا تصلح لتدريب نموذج أو إصدار توقعات.

## التشغيل محلياً

يتطلب Python 3.11 أو أحدث، ولا يحتاج مكتبات خارجية:

    cd aviabet-audit
    python -m venv .venv

Linux/macOS:

    . .venv/bin/activate

Windows PowerShell:

    .venv\Scripts\Activate.ps1

تثبيت المشروع:

    pip install -e .

تحليل ملف:

    aviabet-audit data/sample_rounds.csv

اختبارات:

    python -m unittest discover -s tests -v

## تشغيل بوت Telegram

1. أنشئ بوتاً تملكه عبر BotFather واحفظ التوكن خارج المستودع.
2. انسخ .env.example إلى .env محلياً، أو اضبط المتغيرات في بيئة الاستضافة.
3. اضبط TELEGRAM_BOT_TOKEN.
4. اضبط TELEGRAM_ALLOWED_CHAT_IDS بمعرّفات رقمية للمحادثات المصرّح لها، مفصولة بفواصل. البوت يرفض العمل إذا كانت القائمة فارغة.
5. شغّل:

    aviabet-audit-bot

البوت يقبل ملفات CSV فقط، ويحدد حجم الملف بـ 1 MiB، ولا يخزّن الملفات على القرص. لا تسجل سجلات التشغيل محتوى الملفات أو التوكن.

**لا تضع التوكن في GitHub أو في هذا الملف أو في رسائل المحادثة.** أضفه كـ Secret في منصة الاستضافة عند تجهيزها. لا يحتوي المستودع الحالي على توكن Telegram أو إعداد نشر، لذلك إضافة الكود لا تعني أن البوت أصبح متصلاً أو يعمل على مدار الساعة.

## حدود النتائج الإحصائية

- متوسط/وسيط/مدى المضاعفات وصف للبيانات التي تم رفعها فقط.
- الارتباط من رتبة واحدة واختبار Runs تشخيصيان، وليسا اختباراً معتمداً لسلامة RNG.
- يلزم عدد كبير من الجولات، ومصدر بيانات موثوق، وخطة اختبار محددة مسبقاً، وعينة مستقبلية منفصلة قبل الاستنتاج.
- لا يجوز اعتبار أي نمط في التاريخ ضماناً لنتيجة جولة قادمة.
- لا يمكن تدقيق Commit-Reveal بصورة صحيحة دون مواصفة المزود الدقيقة، والقيمة المنشورة قبل الجولة، والقيم التي كُشفت بعدها. وجود SHA-512 وحده لا يثبت سلامة التوقيت أو سرية النتيجة.

## الأمان والنطاق

الأداة تعمل على ملفات يرفعها المستخدم ولا تتصل بمنصة اللعبة أو واجهات API التابعة لها. استخدمها مع بيانات Demo أو بيانات يملك المستخدم حق تدقيقها. أي اختبار لخوادم Pascal أو مزوّد اللعبة يتطلب تفويضاً صريحاً من الجهة المالكة لتلك الأنظمة.
