# خارطة تنفيذ رُوح — الإصدار الأول

هذه الخارطة تتبع القرارات المعتمدة في `docs/PRODUCT_REQUIREMENTS.md`. تُبنى كل ميزة من الواجهة إلى البيانات وقواعد الأمان ثم الاختبار، ولا تعتبر منجزة لمجرد ظهور شكلها.

## قرارات النطاق
- Android فقط حالياً؛ iOS مؤجل ولا تضاف له ملفات أو إعدادات أو CI حالياً.
- اللغة العربية عند الإطلاق، مع بنية قابلة لإضافة الإنجليزية لاحقاً.
- Firebase Spark مجاني فقط، دون بطاقة أو Billing أو Blaze. Supabase غير معتمد.
- لا يشترط تأكيد البريد قبل الدخول.
- الملف الشخصي: الاسم والبريد والعمر والجنس ومكان السكن والاهتمامات والهدف الشخصي.
- الأسئلة الإضافية اختيارية وقابلة للتخطي والتعديل، وتستخدم لتخصيص المحتوى.
- الإصدار الأول مجاني بالكامل؛ الدفع والكورسات المدفوعة والاشتراكات مؤجلة.
- المحتوى يجمع مواد المالك الجاهزة التي سترسل لاحقاً ومحتوى أصلي يكتبه المساعد ويعتمده دون مراجعة مسبقة من المالك.
- بريد الإدارة المعتمد: `hanen98990@gmail.com`.
