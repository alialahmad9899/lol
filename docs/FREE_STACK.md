# الخدمات المجانية — قرارات النسخة التجريبية

تُستخدم الخطط المجانية فقط. المجانية تعني عدم دفع اشتراك ضمن حدود الاستخدام المنشورة، ولا تعني ضمان التوفر أو السعة أو بقاء الشروط بلا تغيير. نراقب الاستهلاك ونمنع أي تجاوز مدفوع.

## الأدوات المقترحة

| الجزء | الخيار الأول | استخدامه |
|---|---|---|
| تطبيق الهاتف | Flutter | Android وiOS من قاعدة كود واحدة |
| قاعدة البيانات والحسابات | Supabase Free | PostgreSQL وAuth وStorage وRealtime |
| الإشعارات | Firebase Cloud Messaging | Push Notifications |
| لوحة الإدارة | Flutter Web | واجهة الإدارة من نفس منظومة التصميم |
| استضافة لوحة الإدارة | Cloudflare Pages Free | استضافة الملفات الثابتة |
| الفيديو التجريبي | YouTube | دروس عامة أو غير مدرجة وروابط بث |
| الصوت والملفات الصغيرة | Supabase Storage | ضمن حصة التخزين المحدودة |
| المدفوعات في التجربة | شام كاش يدوياً | إثبات تحويل ومراجعة إدارية دون بوابة إلكترونية |

## حدود يجب معرفتها قبل الإطلاق

- Supabase Free يعلن عن 500MB لقاعدة البيانات، و50,000 مستخدم نشط شهرياً، و1GB لتخزين الملفات، وحصص نقل بيانات محدودة.
- مشاريع Supabase المجانية قد تتوقف بعد أسبوع من عدم النشاط، كما توجد حدود لعدد المشاريع النشطة.
- خدمة البريد الافتراضية لـ Supabase مخصصة للتجربة: ترسل فقط إلى عناوين فريق المشروع وبحد حالي 2 رسالة في الساعة. لذلك لا نعتمد عليها لإرسال رسائل تحقق جماعية أو استعادة كلمة المرور للمستخدمين الحقيقيين.
- يمكن تعطيل تأكيد البريد مؤقتاً في بيئة الاختبار فقط، مع إبقاء ذلك قراراً مؤقتاً موثقاً. قبل فتح التسجيل العام نحتاج مسار بريد مجاني موثوقاً أو مراجعة مزود SMTP وشروطه.
- FCM مجاني، بينما رسائل SMS والتحقق الهاتفي ليست مجانية بالضرورة.
- التخزين المجاني لا يناسب رفع مكتبة فيديو كبيرة أو بثاً عالي المشاهدات؛ لا نرفع ملفات فيديو ثقيلة إلى قاعدة البيانات أو التخزين المجاني.
- Cloudflare Pages لديه حدود مجانية للبناء وعدد الملفات وحجم الملف. طلبات Pages Functions تحسب ضمن حدود Workers؛ لا نضيف وظائف خادم إلا عند الحاجة.
- YouTube غير المدرج يخفي الفيديو من البحث العام لكنه لا يمنع من يملك الرابط من مشاركته. لذلك لا نعتبره حماية كاملة للكورسات المدفوعة.
- البث عبر YouTube يتطلب تفعيل البث والتحقق من القناة؛ والبث المباشر من الهاتف له شروط أهلية إضافية. يجب اختبار القناة الفعلية قبل اعتماد تجربة البث.
- لا توجد خدمة مجانية تضمن لنا بثاً خاصاً محمياً وموثوقاً مع تخزين غير محدود وبدون قيود. النسخة التجريبية ستستخدم رابط بث خارجي مع توضيح حدود الحماية.

## قواعد منع التكاليف غير المقصودة

1. لا نفعّل خطة مدفوعة أو رصيداً تجريبياً قابلاً للتحول إلى فاتورة.
2. لا نضيف بطاقة بنكية إلى مزود لغرض تجاوز حصص المجاني.
3. نستخدم بيانات تجريبية ومحتوى محدود الحجم.
4. نضع قيود حجم الملفات ونراقب الحصص.
5. لا نضع أي مفتاح سري داخل تطبيق Flutter أو كود لوحة الويب.
6. مفاتيح الخدمة السرية تبقى على الخادم فقط، وتُحمى الجداول بسياسات RLS.
7. أي خدمة جديدة يجب أن يكون لها خيار مجاني واضح وحدود موثقة قبل اعتمادها.

## تكاليف النشر الخارجي المؤجلة

- يمكن توزيع APK تجريبي على Android مباشرة دون رسوم متجر.
- النشر على Google Play يتطلب رسم تسجيل حساب مطور لمرة واحدة.
- النشر على App Store وTestFlight يتطلب عضوية Apple Developer مدفوعة سنوياً.
- لذلك لا ندخل أي رسوم نشر ضمن مرحلة النموذج التجريبي.
