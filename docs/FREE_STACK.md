# الخدمات المجانية — قرارات النسخة التجريبية

## القرارات الحالية

- **Supabase مستبعد من المشروع**؛ لم ننشئ مشروعاً عليه ولن نستخدم أي مشروع Supabase موجود.
- **YouTube والفيديو والبث المباشر مؤجلة**؛ ليست ضمن أول نسخة تشغيلية.
- لا نفعّل خطة مدفوعة، ولا نضيف وسيلة دفع، ولا نسمح بخدمة أن تتحول تلقائياً إلى فاتورة.
- المرشح التقني للخادم هو Firebase بخطة Spark المجانية، لكن اعتماده النهائي يكون بعد تثبيت نموذج البيانات وقواعد الأمان.
- لا نبدأ ربط التطبيق بخادم حقيقي قبل إقرار مزود الخادم. يمكن استمرار بناء الواجهات ونماذج البيانات محلياً الآن.

## الهيكل المقترح للنسخة التجريبية

| الجزء | الخيار المقترح | الاستخدام |
|---|---|---|
| تطبيق الهاتف | Flutter | Android وiOS من قاعدة كود واحدة |
| الحسابات | Firebase Authentication على Spark | بريد وكلمة مرور، جلسات، إعادة تعيين كلمة المرور |
| قاعدة البيانات | Cloud Firestore على Spark | المستخدمون، الاهتمامات، المحتوى النصي، الدورات، التسجيل والتقدم |
| الإشعارات | Firebase Cloud Messaging | إشعارات التطبيق |
| لوحة الإدارة | Flutter Web | واجهة منفصلة للأدوار الإدارية |
| استضافة لوحة الإدارة | Cloudflare Pages Free (مرشح) | ملفات الويب الثابتة |
| ملفات الصور والصوت والفيديو | مؤجلة | لا نستخدم Firebase Storage لأنه يتطلب Blaze |
| الفيديو والبث | مؤجلان | لا YouTube ولا مزود بث في النسخة الحالية |
| المدفوعات | مؤجلة من ناحية التحصيل الآلي | يمكن تجهيز نموذج طلب/مراجعة إدارية دون تفعيل بوابة أو رفع ملفات حالياً |

## لماذا Firebase مرشح مناسب الآن؟

الخطة Spark لا تتطلب إدخال معلومات دفع للبدء، وتوفر Authentication لمعظم طرق الدخول وFirebase Cloud Messaging دون رسوم. كما تتيح حصة مجانية لـ Cloud Firestore.

الحدود الرسمية المنشورة لـ Firestore على الخطة المجانية:
- 1 GiB بيانات مخزنة.
- 50,000 قراءة مستند يومياً.
- 20,000 كتابة يومياً.
- 20,000 حذف يومياً.
- 10 GiB نقل بيانات صادرة شهرياً.

على Spark، تجاوز حصة منتج ذي حد مجاني يؤدي إلى إيقاف استخدام ذلك المنتج لبقية دورة الاستخدام، لا إلى فوترة تلقائية. نراقب حدود الاستخدام ونختبر سلوك التطبيق عند الوصول إليها.

## قيود مهمة قبل اعتماد Firebase

- Firebase Storage غير متاح لمشاريع Spark؛ استخدام حاويات Cloud Storage يتطلب Blaze. لذلك لا نبني رفع صورة الملف الشخصي أو ملفات إثبات الدفع على Firebase Storage الآن.
- Firestore قاعدة بيانات للمعلومات والبيانات الوصفية وليست مكاناً لتخزين ملفات الوسائط.
- المصادقة عبر رقم الهاتف ورسائل SMS ليست مجانية بالضرورة؛ لا نستخدم SMS في النسخة التجريبية.
- لا نستخدم Cloud Functions أو أي منتج يتطلب Blaze.
- نستخدم قواعد أمان Firestore لحماية كل مجموعة، ولا نعتمد على إخفاء زر في التطبيق كوسيلة صلاحيات.
- دور المدير لا يُخزن في بيانات يغيّرها المستخدم بنفسه. نستخدم هوية/قائمة مدير موثوقة وقواعد وصول مقيدة، ونختبر منع المستخدم العادي من تنفيذ عمليات الإدارة.
- FCM مخصص للإشعارات؛ لا يحتوي على بيانات حساسة ولا يمنح صلاحية فتح محتوى مدفوع.
- عدم وجود تخزين ملفات يعني تأجيل صور المستخدمين المرفوعة وإثباتات الدفع كملفات حتى اختيار تخزين مجاني مناسب دون إلزام خطة مدفوعة.

## ما يدخل في أول نسخة تشغيلية دون وسائط خارجية؟

- إنشاء الحساب وتسجيل الدخول وتسجيل الخروج.
- الملف الشخصي والاهتمامات والأهداف.
- التصنيفات والمحتوى النصي ووصف الجلسات.
- برامج وتحديات ذات بيانات نصية.
- قائمة الكورسات والدروس ومعلوماتها.
- التسجيل في الكورسات المجانية وتتبع التقدم.
- نموذج طلب تسجيل/دفع يدوي مع مرجع تحويل نصي، دون رفع صورة في هذه المرحلة.
- لوحة إدارة للمحتوى والمستخدمين والطلبات وفق قواعد أمان دقيقة.
- إشعارات أساسية عندما ننتهي من إعداد FCM.

ستظل الجلسات الصوتية والمرئية وملفات المستخدم والبث والكورسات التي تحتاج إلى تشغيل ملفات فعلية مؤجلة حتى تجهيز وسيط مجاني ملائم.

## قواعد منع التكاليف غير المقصودة

1. لا نفعّل Blaze أو أي خطة مدفوعة.
2. لا نضيف بطاقة أو حساب فوترة إلى Firebase.
3. لا ننشئ أي مورد Cloud يتطلب Billing.
4. لا نستخدم Firebase Storage أو Cloud Functions ضمن هذه النسخة.
5. نراقب حصص Firestore ونختبر سيناريو نفاد الحصة.
6. لا نضع مفاتيح خدمة إدارية أو أسراراً في تطبيق Flutter أو لوحة الويب.
7. كل بيانات المستخدم محمية بقواعد وصول فعلية في الخادم.
8. أي خدمة جديدة تمر بمراجعة رسمية للتسعير والحدود قبل استخدامها.

## تكاليف النشر الخارجي المؤجلة

- يمكن توزيع APK تجريبي على Android مباشرة دون رسوم متجر.
- النشر على Google Play يتطلب رسم تسجيل حساب مطور لمرة واحدة.
- النشر على App Store وTestFlight يتطلب عضوية Apple Developer مدفوعة سنوياً.
- لذلك لا ندخل أي رسوم نشر ضمن مرحلة النموذج التجريبي.
