- سبق أن نجح CI الأساسي وبناء APK تجريبي قبل أحدث مجموعة إضافات.
- لا توجد نتيجة مؤكدة في هذا السجل تثبت نجاح أحدث تعديلات Dart وقواعد Firestore واختبارات المحاكي معاً. يجب مراجعة تشغيل GitHub Actions الأحدث قبل اعتماد النسخة.
