## الوظائف الموجودة في الكود بفرع التطوير

- Firebase initialization لإعداد Android المسجل.
- تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور والتحقق من البريد وإعادة إرسال رسالة التحقق.
- اختيار الاهتمامات والهدف الأساسي في التسجيل.
- بوابة تمنع الحساب غير المؤكد من دخول الواجهات الرئيسية.
- ملف شخصي يعرض الاسم والبريد والاهتمامات والهدف ويسمح بتعديل الحقول المسموح بها.
- استكشاف تصنيفات ومحتوى منشور مع البحث والتصفية والتفاصيل النصية.
- محفوظات شخصية وعلامة إكمال المحتوى ومكتبة للمحفوظات والمحتوى المكتمل.
- كتالوج كورسات ودروس نصية وتسجيل مجاني وتتبع تقدم.
- كتالوج برامج وتحديات وأيام مهام وتتبع إنجاز.
- لوحة إدارة أولية لإضافة وتعديل ونشر التصنيفات والمحتوى والكورسات والبرامج ودروسها وأيامها.
- دليل إداري للبحث وعرض ملفات المستخدمين بصلاحية قراءة فقط.
- طلبات تحويل نصية للكورسات المدفوعة، مع مراجعة بشرية واعتماد التسجيل في معاملة Firestore واحدة.
- قواعد Firestore أولية لخصوصية الملفات الشخصية والمكتبة والدروس المدفوعة والتسجيلات وطلبات الدفع.

## الاختبارات والتحقق

- يوجد GitHub Actions لتنسيق Dart والتحليل والاختبارات وبناء APK تجريبي.
- يوجد الآن اختبار Firestore Emulator باستخدام Node.js داخل `tests/firestore.rules.test.mjs`، وتم ربطه بخط CI.
- سبق أن نجح تشغيل CI الأساسي وبناء APK تجريبي قبل أحدث مجموعة إضافات.
- **لا توجد نتيجة مؤكدة في هذا السجل تثبت نجاح أحدث تعديلات Dart وقواعد Firestore واختبارات المحاكي معاً.** يجب مراجعة تشغيل GitHub Actions الأحدث قبل اعتماد هذه النسخة.
- لا يوجد اختبار حي مؤكد ضد Firebase Project حتى الآن.
