# رُوح — ابدأ من الداخل

مشروع تطبيق رُوح للدكتور خالد علوش. تطبيق عربي للوعي وتطوير الذات والاسترخاء والتركيز وبناء العادات، مع برامج وكورسات ولوحة إدارة.

## الحالة الفعلية في فرع التطوير

الموجود حالياً في `feature/rooh-flutter-foundation`:

- شعار رُوح مستخدم داخل واجهة التطبيق.
- تسجيل الدخول وإنشاء الحساب والتحقق من البريد واستعادة كلمة المرور، مع اختيار الاهتمامات والهدف الشخصي.
- بوابة جلسة Firebase وتسجيل الخروج.
- ملف شخصي يعرض الاسم والبريد والاهتمامات والهدف مع إمكانية تعديل البيانات المسموح بها.
- استكشاف التصنيفات والمحتوى المنشور، مع البحث والتصفية وصفحة تفاصيل نصية.
- حفظ الجلسات والتمارين في مكتبة شخصية، وتسجيل المحتوى المكتمل وعرض المحفوظات والإنجازات.
- كتالوج الكورسات المنشورة، والتسجيل المجاني، والدروس النصية للمسجلين، وحفظ التقدم.
- كتالوج البرامج والتحديات المنشورة، والتسجيل المجاني وتتبع الأيام المنجزة.
- لوحة إدارة أولية لإدارة التصنيفات والمحتوى والكورسات والبرامج ودروسها وأيامها، مع دليل عرض للمستخدمين والبحث في بياناتهم.
- طلبات دفع يدوي للكورسات المدفوعة عبر رقم مرجع نصي، مع شاشة إدارة للمراجعة والاعتماد أو الرفض.
- قواعد Firestore أولية لحماية ملفات المستخدمين والدروس المدفوعة والتسجيلات وطلبات الدفع.
- إعداد Android البرمجي موجود، مع Google Services وملف إعداد التطبيق المسجل.

**هذه ليست نسخة إطلاق نهائية بعد.** لم نتحقق من تفعيل Email/Password في Firebase Console، ولا من إنشاء Firestore أو نشر القواعد واختبارها على المشروع السحابي. لم تُنشأ صلاحية المدير الأولى بعد. دليل المستخدمين للعرض والبحث فقط؛ إيقاف الحسابات أو حذفها وإحصاءات الإدارة وسجل التدقيق ما زالت غير مكتملة. الإشعارات ودعم iOS الفعلي والاختبارات الشاملة ما زالت غير مكتملة.

## المتطلبات المحلية

- Flutter SDK (Dart 3.12 أو أحدث).
- Android Studio أو Android SDK لتشغيل وبناء Android.
- Xcode على macOS فقط لبناء وتشغيل iOS.
- Node.js لاستخدام Firebase CLI أثناء إعداد المشروع.

## الاختبارات الأمنية

تحتاج اختبارات Firestore Emulator إلى Node.js وJava، ولا تتصل بمشروع Firebase الحقيقي:

```bash
npm install
npm run test:rules
```

## التشغيل

بعد تثبيت Flutter:

```bash
flutter pub get
dart format lib test
flutter analyze --fatal-infos
flutter test
flutter run
npm install
npm run test:rules
```

## ربط Firebase

نعتمد Firebase Spark فقط دون بطاقة أو Billing أو Storage أو Cloud Functions. راجع:

- `docs/FIREBASE_SETUP.md` — حالة مشروع Firebase وخطوات تفعيل Auth وFirestore ونشر القواعد.
- `docs/FIRESTORE_SCHEMA.md` — شكل المستندات وحقول المحتوى والمحفوظات والتقدم والكورسات والبرامج والتسجيلات وطلبات الدفع.
- `tests/firestore.rules.test.mjs` — اختبارات صلاحيات Firestore عبر المحاكي.
- `docs/FREE_STACK.md` — الخدمات والحدود المجانية المعتمدة.
- `docs/PRODUCT_ROADMAP.md` — مراحل التطوير وما اكتمل وما بقي.

لا تضع Service Account JSON أو مفاتيح Admin SDK داخل التطبيق أو GitHub.
