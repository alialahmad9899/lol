# رُوح — ابدأ من الداخل

مشروع تطبيق رُوح للوعي وتطوير الذات والاسترخاء والتركيز وبناء العادات.

## نطاق الإصدار الأول
- Android فقط؛ دعم iOS مؤجل.
- العربية عند الإطلاق، مع قابلية إضافة الإنجليزية لاحقاً.
- مجاني بالكامل؛ لا اشتراكات أو مدفوعات أو كورسات مدفوعة في الإصدار الأول.
- لا يشترط تأكيد البريد الإلكتروني قبل الدخول.
- الملف الشخصي يتضمن الاسم والبريد والعمر والجنس ومكان السكن والاهتمامات والهدف الشخصي.
- المحتوى يجمع المواد الجاهزة التي سيقدمها مالك المشروع لاحقاً ومحتوى أصلياً جديداً ينشئه المساعد.
- Firebase Spark فقط دون بطاقة أو Billing أو Blaze. Supabase غير معتمد.
- بريد الإدارة المعتمد: `hanen98990@gmail.com`.

راجع `docs/PRODUCT_REQUIREMENTS.md` للقرارات الكاملة، و`docs/PRODUCT_ROADMAP.md` لخطة التنفيذ.

## الحالة الفعلية في فرع التطوير
الموجود حالياً في `feature/rooh-flutter-foundation`:
- شعار رُوح مستخدم داخل واجهة التطبيق.
- تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور.
- بوابة جلسة Firebase وتسجيل الخروج.
- ملف شخصي أولي للاسم والبريد والاهتمامات والهدف.
- استكشاف التصنيفات والمحتوى المنشور مع البحث والتصفية والتفاصيل النصية.
- حفظ المحتوى وعرض المكتبة الشخصية وتسجيل المحتوى المكتمل.
- كتالوج البرامج والتحديات المجانية ومهام الأيام وتتبع الإنجاز.
- كتالوج كورسات ودروس نصية وتسجيل مجاني وتتبع التقدم.
- لوحة إدارة أولية للمحتوى والتصنيفات والبرامج والكورسات، ودليل عرض للمستخدمين.
- قواعد Firestore أولية واختبارات للمحاكي مرتبطة بخط CI.

**هذه ليست نسخة إطلاق نهائية.** يجب مواءمة الكود مع قرارات المنتج، خصوصاً إلغاء حاجز تأكيد البريد، وإضافة حقول الملف الشخصي الجديدة، وعزل أي واجهات دفع قديمة عن الإصدار المجاني. لا توجد نتيجة مؤكدة في هذا السجل لنجاح أحدث اختبارات Dart وقواعد المحاكي معاً، ولا يوجد تحقق حي مكتمل على Firebase السحابي.

## المتطلبات المحلية
- Flutter SDK متوافق مع إصدار المشروع.
- Android Studio أو Android SDK لتشغيل وبناء Android.
- Node.js وJava لاختبارات Firestore Emulator.

## الاختبارات
تحتاج اختبارات Firestore Emulator إلى Node.js وJava، ولا تتصل بمشروع Firebase الحقيقي:

```bash
npm install
npm run test:rules
```

بعد تثبيت Flutter:

```bash
flutter pub get
dart format lib test
flutter analyze --fatal-infos
flutter test
flutter build apk --debug
npm install
npm run test:rules
```

## ربط Firebase
نعتمد Firebase Spark فقط. راجع:
- `docs/FIREBASE_SETUP.md` — إعداد Firebase.
- `docs/FIRESTORE_SCHEMA.md` — مخطط البيانات.
- `tests/firestore.rules.test.mjs` — اختبارات صلاحيات Firestore.
- `docs/IMPLEMENTATION_STATUS.md` — الحالة الفعلية وما لم يتم التحقق منه.

لا تضع Service Account JSON أو مفاتيح Admin SDK داخل التطبيق أو GitHub.

## الفروع
التطوير يتم على `feature/rooh-flutter-foundation`، ولا يُدمج في `master` قبل اجتياز المراجعة والاختبارات وقرار المالك.
