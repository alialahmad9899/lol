# رُوح — ابدأ من الداخل

تطبيق Android عربي للوعي بالذات والاسترخاء والتركيز وبناء العادات.

## نطاق الإصدار الأول

- Android فقط؛ iOS مؤجل.
- اللغة العربية واتجاه RTL.
- التسجيل بالبريد وكلمة المرور، ولا يُشترط تأكيد البريد قبل الدخول.
- ملف شخصي يتضمن الاسم والبريد والعمر والجنس والمدينة والدولة والاهتمامات والهدف وتفضيلات اختيارية.
- محتوى أصلي عربي مجاني، مع إمكانية إضافة مواد المالك الجاهزة لاحقاً دون نسب محتوى غير موثق إليه.
- كورسات وبرامج مجانية فقط؛ الدفع والاشتراكات مؤجلة.
- Firebase Spark المجاني فقط، دون بطاقة أو Blaze أو Supabase.
- بريد المدير المعتمد في متطلبات المشروع: `hanen98990@gmail.com`.

راجع `docs/PRODUCT_REQUIREMENTS.md` للقرارات الكاملة.

## ما تم تنفيذه في فرع التطوير

- تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور وبوابة الجلسة.
- شاشة تسجيل مع حقول اختيارية للعمر والجنس والمدينة والدولة وتفضيلات المحتوى والوقت.
- ملف شخصي يعرض البيانات ويتيح تعديلها ومسح الإجابات الاختيارية.
- استكشاف المحتوى المنشور حسب التصنيف مع البحث والتصفية والتفاصيل.
- حفظ المحتوى ومكتبتي الشخصية وتسجيل الإكمال.
- كورسات وبرامج مجانية مع تسجيل وتتبع التقدم.
- لوحة إدارة لإدارة التصنيفات والمحتوى والكورسات والبرامج والدروس والأيام.
- صفحة إدارية لعرض المستخدمين.
- زر في لوحة الإدارة لإضافة مكتبة بداية عربية: 6 تصنيفات، 13 جلسة/مادة، كورس بأربعة دروس، وبرنامج من 7 أيام. ينشئ السجلات الناقصة فقط ولا يستبدل السجلات الموجودة.
- قواعد Firestore واختبارات Emulator، وفهارس الكورسات والبرامج المجانية.
- اسم التطبيق الظاهر في Android: «رُوح».

## الاختبارات والبناء

آخر تشغيل ناجح قبل تحديث وثائق البناء: GitHub Actions رقم 144 على commit `693cf1c`.
اجتازت قواعد Firestore والتحليل واختبارات Flutter وبناء APK ورفع artifact.

مسارات البناء المحلية:

```bash
npm install
npm run test:rules
flutter pub get
dart format lib test
flutter analyze --fatal-infos
flutter test --coverage
flutter build apk --debug
```

راجع صفحة [تشغيل CI](https://github.com/alialahmad9899/lol/actions) للحصول على artifacts الحديثة.

## ما لم يكتمل بعد

- نشر `firestore.rules` و`firestore.indexes.json` على مشروع Firebase الحقيقي.
- إنشاء مستند المدير في `admins/{uid}` من Firebase Console باستخدام UID الصحيح للبريد المعتمد.
- بعد تفعيل المدير: فتح لوحة الإدارة واختيار **إعداد مكتبة البداية المجانية** لإضافة المحتوى إلى قاعدة Firebase الفعلية.
- اختبار تسجيل مستخدم حقيقي وقراءة وكتابة بياناته على Firebase السحابي.
- تجربة APK على جهاز Android فعلي والتحقق من تجربة الاستخدام.
- أيقونة Launcher نهائية وSplash مخصصان لم يكتمل تجهيزهما.
- حذف الحساب وبياناته، وسياسة الخصوصية والشروط النهائية، وإشعارات Push.
- الصوت والفيديو والبث المباشر ورفع الملفات مؤجلة.
- نسخة Release موقّعة بمفتاح إصدار خاص بالمالك مطلوبة قبل النشر العام.

وجود القواعد في المستودع أو نجاح Emulator لا يعني نشر القواعد على Firebase. كما أن APK التجريبي لا يثبت وحده نجاح تكامل Firebase السحابي.
